🤖 Minecraft AFK Bot

A lightweight Minecraft Java AFK bot powered by Mineflayer. It connects to a server and performs small movements to keep it from shutting down due to inactivity.

The bot is a long-running Node.js process, so it does not run on this website. Run it on your own machine or on a host that supports always-on processes.

Quick start

npm install
# edit config.json with your server host, port and bot username
node bot.js

Configuration (config.json)

  • serverHost: IP or domain of your Minecraft server
  • serverPort: server port (default 25565)
  • botUsername: the bot's in-game name
  • botChunk: radius of loaded chunks (recommended 1–6)
