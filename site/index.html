Minecraft AFK Bot

A lightweight Minecraft Java AFK bot powered by Mineflayer. It connects to a server and moves periodically to keep it from going idle.

The bot is a long-running Node.js process, so it runs on your own machine or a server rather than on this site.

Quick start

npm install
# edit config.json with your server host, port and bot username
node bot.js
